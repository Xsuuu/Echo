# 回声：App 与管理后台页面功能说明

**项目名称：** 回声  
**文档用途：** 明确 App 用户端与管理后台的页面结构、核心功能和当前不做的范围  
**当前原则：** 先把大体功能做出来，扩展能力后续再加
**当前原则：** 整体颜色风格-浅紫色

## 1. App 用户端

App 底部 Tab 确定为：

```text
消息｜动态｜我的
```

## 2. 消息

消息页采用类似微信的会话列表形式，不拆分系统通知、互动通知等复杂分类。

### 2.1 页面结构

```text
消息
├── 粉丝群聊
└── 偶像私聊
```

### 2.2 粉丝群聊

粉丝群聊优先级最高，是 App 第一阶段最重要的消息能力。

功能：

- 展示粉丝群聊会话。
- 用户可以在群聊中发送文字消息。
- 多个 AI 粉丝在群聊中回复用户。
- 群聊展示粉丝头像、昵称、发言内容和时间。
- 展示最后一条消息。
- 展示未读数量。
- 保存群聊历史记录。

第一版先做默认粉丝群聊，不做复杂群管理。

### 2.3 偶像私聊

偶像私聊指用户与其他使用本软件的用户进行私聊。

功能：

- 展示偶像私聊会话。
- 用户可以与其他用户一对一发送文字消息。
- 展示最后一条消息。
- 展示未读数量。
- 保存私聊历史记录。
- 可从其他用户偶像主页发起私聊，具体入口后续按页面设计落地。

### 2.4 当前不做

- 不做粉丝私聊。
- 不做系统通知会话。
- 不做消息页内的互动、私聊、通知多 Tab。
- 不做语音聊天。
- 不做视频聊天。

## 3. 动态

动态页做类似微博的信息流，是用户发布内容、浏览内容、查看其他偶像主页的核心入口。

### 3.1 页面结构

```text
动态
├── 热搜榜单
├── 关注
├── 推荐
└── 最新
```

### 3.2 热搜榜单

热搜榜单只做热门话题相关能力。

功能：

- 展示热门话题列表。
- 点击话题进入话题详情。
- 话题详情展示该话题下的评论或讨论内容。
- 话题详情展示关联偶像。
- 点击关联偶像可进入该用户的偶像主页。

当前不做：

- 不做热门动态排行。
- 不做粉丝增长榜。
- 不做应援榜。
- 不做复杂榜单算法。

### 3.3 关注

关注页只展示自己关注的偶像发布的动态。

功能：

- 展示已关注偶像的动态。
- 点击偶像头像或昵称进入偶像主页。
- 支持进入动态详情，具体详情能力以后续动态功能为准。

当前不混入推荐内容和官方内容。

### 3.4 推荐

推荐页展示推荐的其他偶像动态，以及后续可能发布的官方内容。

功能：

- 展示推荐偶像的动态。
- 展示官方内容。
- 点击偶像头像或昵称进入偶像主页。

第一版推荐规则可以先简单处理，不做复杂个性化推荐。

### 3.5 最新

最新页展示内容范围与推荐页一致，但排序规则不同。

功能：

- 展示其他偶像动态。
- 展示官方内容。
- 按发布时间倒序排列。
- 点击偶像头像或昵称进入偶像主页。

### 3.6 动态基础功能

第一版动态基础功能：

- 发布文字动态。
- 查看动态列表。
- 查看动态详情。
- 点赞动态。
- 评论动态。
- 删除自己的动态。
- 查看 AI 粉丝在动态下的回应。
- 点击用户头像或昵称进入偶像主页。
- 关注或取消关注其他偶像。

### 3.7 当前不做

- 不做评论详情页。
- 不做复杂转发。
- 不做图片、音频、视频动态。
- 不做复杂推荐算法。

## 4. 我的

我的页面只保留核心个人入口和设置入口。

### 4.1 页面结构

```text
我的
├── 偶像资料
├── 我的动态
└── 设置
    ├── 偶像设置
    ├── 粉丝设置
    ├── 通知设置
    ├── 隐私与安全
    ├── 账号设置
    └── 反馈
```

### 4.2 偶像资料

偶像资料是用户对外展示的主页资料。

功能：

- 展示头像。
- 展示偶像昵称。
- 展示个人简介。
- 展示标签。
- 展示粉丝数。
- 展示关注数。
- 展示动态数。
- 提供编辑按钮。
- 支持编辑偶像资料。

### 4.3 我的动态

功能：

- 展示自己发布过的动态。
- 点击进入动态详情。
- 删除自己的动态。

### 4.4 设置

#### 偶像设置

偶像设置用于配置给 AI 使用的偶像设定，不等同于对外展示资料。

功能：

- 偶像定位。
- 人设关键词。
- 舞台风格。
- 希望粉丝如何看待自己。
- 不希望粉丝如何评价自己。
- 希望动态被怎样回应。
- 恋爱边界。
- 公开形象边界。

#### 粉丝设置

功能：

- 粉丝类型偏好。
- 粉丝互动频率。
- 粉丝群聊活跃度。
- 是否允许粉丝主动发言。
- 是否允许暧昧或恋爱氛围。
- 粉丝称呼设置。
- 粉丝问卷。

#### 通知设置

功能：

- 消息通知开关。
- 群聊通知开关。
- 私聊通知开关。
- 动态互动通知开关。
- 安静时段。

#### 隐私与安全

功能：

- 隐私设置。
- 黑名单。
- 举报入口。
- 数据安全说明。

#### 账号设置

功能：

- 手机号绑定。
- 修改密码。
- 登录设备管理。
- 注销账号。
- 退出登录。

#### 反馈

功能：

- 提交软件反馈。
- 提交问题描述。
- 上传反馈截图，后续支持。
- 查看反馈处理状态，后续支持。

## 5. 偶像主页

用户之间可以互相点击进入偶像主页。

功能：

- 展示偶像头像。
- 展示偶像昵称。
- 展示简介。
- 展示标签。
- 展示粉丝数。
- 展示关注数。
- 展示动态数。
- 展示该用户发布的动态。
- 关注或取消关注。
- 发起偶像私聊，后续按私聊入口设计落地。

## 6. 管理后台

管理后台建议采用：

```text
Vue 3 + TypeScript
```

后台页面用于管理账号、用户、内容、话题、会话、账单、运营配置和举报反馈。

## 7. 后台页面结构

```text
管理后台
├── 登录页
├── 账号管理
├── 用户中心
├── 动态中心
├── 话题管理
├── 偶像主页审核
├── 会话中心
├── 账单管理
├── 抽奖管理
├── 问卷管理
├── 举报与反馈管理
├── 全局参数管理
├── 广告管理
├── 优惠券管理
├── 徽章管理
└── 会员等级管理
```

## 8. 登录页

功能：

- 管理员登录。
- 登录失败提示。
- 登录状态保存。
- 退出登录。

## 9. 账号管理

原“权限中心”改名为“账号管理”，功能保持不变。

### 9.1 功能结构

```text
账号管理
├── 管理员账号管理
└── 菜单权限
    ├── 页面权限
    └── 页面内功能权限
```

### 9.2 管理员账号管理

功能：

- 新增管理员账号。
- 编辑管理员账号。
- 启用或停用管理员账号。
- 重置管理员密码。
- 分配菜单权限。

### 9.3 菜单权限

功能：

- 配置管理员可访问的后台页面。
- 配置管理员在某个页面下可使用的功能按钮。

示例：

- 是否可访问用户中心。
- 是否可访问账单管理。
- 是否可编辑用户资料。
- 是否可进行状态管理。
- 是否可发放优惠券。
- 是否可修改星光。

当前不做其他权限模块。

## 10. 用户中心

### 10.1 用户列表字段

用户中心列表字段：

| 字段 | 说明 |
| --- | --- |
| 用户ID | 用户唯一标识 |
| 偶像昵称 | 用户对外展示昵称 |
| 会员等级 | 当前会员等级 |
| 手机号 | 用户绑定手机号 |
| 最近消费时间 | 最近一次消费时间 |
| 总消费金额 | 累计消费金额 |
| 星光 | 当前星光余额 |
| 获取徽章总数 | 用户获得的徽章数量 |
| 获取优惠券总数 | 用户获得的优惠券数量 |
| 注册时间 | 用户注册时间 |
| 用户状态 | 正常、禁用、禁言等 |
| 操作 | 详情、编辑、状态管理等 |

不展示真实姓名。

### 10.2 用户列表操作

操作按钮：

- 详情。
- 编辑。
- 状态管理。
- 等级管理。
- 星光管理。
- 徽章管理。
- 优惠券管理。

状态管理用于：

- 禁用账号。
- 恢复账号。
- 禁言几天。
- 解除禁言。
- 后续其他用户状态调整。

### 10.3 用户详情页

展示：

- 基础信息。
- 偶像资料。
- 偶像设置。
- 粉丝设置。
- AI 记忆。
- 动态记录。
- 会话记录。
- 消费记录。
- 优惠券。
- 徽章。
- 反馈记录。

不展示操作日志。

## 11. 动态中心

功能：

- 查看用户动态列表。
- 查看动态详情。
- 下架动态。
- 删除违规动态。
- 查看动态评论。
- 发布官方动态。
- 编辑官方动态。
- 下架官方动态。
- 将官方动态展示到推荐或最新内容中。

## 12. 话题管理

功能：

- 创建话题。
- 编辑话题。
- 上线或下线话题。
- 配置话题排序。
- 配置话题热度。
- 查看话题下的评论或讨论。
- 配置话题关联偶像。

话题管理服务于 App 动态页的热搜榜单。

## 13. 偶像主页审核

功能：

- 审核偶像头像。
- 审核偶像昵称。
- 审核个人简介。
- 审核标签。
- 审核其他主页展示信息。
- 通过审核。
- 驳回审核。
- 标记违规内容。

## 14. 会话中心

功能：

- 查看粉丝群聊记录。
- 查看偶像私聊记录。
- 查看会话异常。
- 查看被举报的会话内容。
- 处理违规会话。

会话内容涉及隐私，后续需要结合账号管理中的菜单权限和功能权限控制可见范围。

## 15. 账单管理

AI 生成记录放到账单管理里，用于查看星光充值和消耗情况。

功能：

- 充值记录。
- 消费记录。
- 星光流水。
- AI 生成消耗记录。
- 会员购买记录。
- 退款记录。

用于查看：

- 用户充值了多少。
- 用户用了多少星光。
- AI 生成消耗了多少星光。
- 会员购买和退款情况。

## 16. 抽奖管理

功能：

- 奖池管理。
- 奖品管理。
- 抽奖规则。
- 抽奖记录。
- 中奖发放。

## 17. 问卷管理

功能：

- 创建问卷。
- 编辑问卷。
- 配置题目。
- 配置选项。
- 配置题目排序。
- 配置题目是否必答。
- 发布问卷。
- 下线问卷。
- 查看用户问卷答案。

问卷用于生成或调整粉丝设置、偶像设置和互动偏好。

## 18. 举报与反馈管理

举报与反馈管理用于处理用户举报和软件反馈。

功能：

- 举报偶像。
- 举报粉丝言论。
- 举报动态。
- 举报话题。
- 软件反馈。
- 查看举报详情。
- 处理举报。
- 标记处理结果。
- 查看反馈内容。
- 处理软件反馈。

## 19. 全局参数管理

功能：

- 违禁词配置。
- AI 安全规则。
- 消息频率配置。
- 群聊发言上限。
- 每日 AI 调用上限。
- 推荐权重配置。
- 热搜权重配置。
- 注册开关。
- 维护公告。
- 版本更新配置。

违禁词可以支持 JSON 配置，但后台应保留配置名称、配置类型、配置值、启用状态和修改时间。

## 20. 广告管理

功能：

- Banner 管理。
- 弹窗管理。
- 信息流广告管理。
- 跳转链接配置。
- 上线时间配置。
- 下线时间配置。
- 启用或停用广告。

## 21. 优惠券管理

功能：

- 创建优惠券。
- 编辑优惠券。
- 发放优惠券。
- 查看用户优惠券。
- 设置优惠券有效期。
- 设置优惠券使用条件。
- 启用或停用优惠券。

## 22. 徽章管理

功能：

- 创建徽章。
- 编辑徽章。
- 发放徽章。
- 查看用户徽章。
- 配置徽章获得条件。
- 启用或停用徽章。

## 23. 会员等级管理

功能：

- 创建会员等级。
- 编辑会员等级。
- 设置等级名称。
- 设置等级权益。
- 设置等级价格。
- 设置等级有效期。
- 启用或停用会员等级。

## 24. 当前明确不做

App 当前不做：

- 粉丝私聊。
- 系统通知会话。
- 评论详情页。
- 语音聊天。
- 视频聊天。
- 图片、音频、视频动态。
- 复杂推荐算法。

后台当前不做：

- 真实姓名字段。
- 用户详情页操作日志。
- 独立 AI 生成记录页面。
- 除账号管理内菜单权限之外的复杂权限模块。

## 25. 名词确认

虚拟币名称确定为：

```text
星光
```

星光用于表示用户可充值、可消费的虚拟资产。后续涉及 AI 生成、会员、抽奖、优惠券等消费记录时，统一使用“星光”命名。
